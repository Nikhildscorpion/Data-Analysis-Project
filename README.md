# TRADING INTERACTIVE DASHBOARD
Developed an interactive Trading & Savings Dashboard in Excel with automated KPI calculations, financial tracking, and visual reporting.
Built dynamic Savings Data and Trading Data input sheets that automatically update dashboard metrics and calendar views.
Created charts to analyze savings progress, weekly target vs. actual performance, saved vs. remaining balance, and financial milestones.
Implemented automated weekly tracking using Excel formulas, conditional formatting, data validation, and dashboard visualizations.
